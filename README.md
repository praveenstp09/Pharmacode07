# PharmaCode07 Exams – Pharmacy Model Papers & Mock Test Platform

**PharmaCode07 Exams** is a modern, responsive, and student-centric educational e-commerce platform designed specifically for **Pharmacy students and competitive pharmacist exam aspirants** (GSSSB Junior Pharmacist, UPSSSC, RRB, AIIMS, GPAT).

Students can easily browse, purchase, and attempt **120 MCQ Model Papers, CBT Mock Tests, Previous Year Questions (PYQs), and Digital Study Materials**.

---

## 🌟 Key Features

* **🎯 120 MCQ Model Papers & CBT Mock Test Engine:**
  * Real Computer-Based Test (CBT) interface with countdown timer and auto-submit.
  * Interactive 120-question palette (Answered, Unanswered, Marked for Review, Not Visited).
  * Strict negative marking (-0.25) and instant scorecard generation.
* **🔍 Question-by-Question Detailed Analysis:**
  * Post-exam solution review showing student's chosen option vs. correct option.
  * In-depth clinical, pharmacological, and jurisdictional explanations for every question.
  * Reattempt facility to retake mock tests.
* **💳 E-Commerce & Dual Checkout:**
  * **Simulated Instant Payment:** For rapid testing and immediate student enrollment.
  * **Razorpay Online Gateway:** Secure checkout supporting Indian UPI (GPay, PhonePe, Paytm), Cards, and NetBanking with HMAC-SHA256 signature verification.
  * **Coupon & Promo Engine:** Real-time discount validation (e.g. `PHARMA10`, `WELCOME50`).
* **👨‍🎓 Student Dashboard:**
  * Active test series tracker with progress indicator.
  * Attempt history with scorecards, accuracy metrics, and review links.
  * Direct download access for unlocked PDF revision notes and drug charts.
* **⚙️ Admin Control Panel:**
  * Comprehensive dashboard analytics (Revenue, Orders, Students, Attempts).
  * **120 MCQ Question Builder:** Create custom mock papers with questions, 4 options, and clinical explanations.
  * Coupon management, order tracking, and student database management.
* **📱 100% Mobile Responsive:**
  * Optimized for Android, iOS, tablets, and desktop devices.

---

## 🛠️ Tech Stack

* **Frontend:** React 18 (Vite), Tailwind CSS, Lucide Icons, React Router v6, Canvas Confetti.
* **Backend:** Node.js, Express.js, JSON Web Tokens (JWT), bcryptjs, Morgan.
* **Database:** MongoDB Atlas (Mongoose 8) with indexed collections.
* **Payments:** Razorpay API + Sandbox simulated checkout.

## 🚀 Getting Started

### 1. Prerequisites
* Node.js (v18+)
* npm (v9+)
* MongoDB Atlas account or local MongoDB

### 2. Backend Setup
```bash
cd backend
npm install
cp .env.example .env
# Configure MONGO_URI in .env
npm start
```

### 3. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.
